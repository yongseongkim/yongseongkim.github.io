비즈니스와 프로덕트를 이해하고 기술로 문제를 해결하는 일을 좋아합니다.
Claude Code와 Codex 같은 AI 에이전트로 구현이 쉬워질수록, 개발자는 무엇을 만들고 개선할지 결정하고 에이전트의 결과와 실제 서비스를 꾸준히 관찰해야 한다고 생각합니다.
AI 에이전트를 구성할 때에도 각 단계의 메트릭과 로그를 남겨 어디에서 문제가 발생했는지 추적하고 디버깅할 수 있어야 합니다.
현재 타다에서 서버 개발을 중심으로 배차, 운행요금, 위치정보 등 라이드헤일링 서비스의 핵심 흐름을 데이터와 지표로 확인하고 개선하고 있습니다.
iOS 개발을 시작으로 여러 기술 스택을 경험했으며, 지금은 제품 전체를 이해하고 더 나은 결정을 내리는 개발자가 되는 데 관심이 많습니다.

- 서버 개발
  - Spring, Kotlin, MySQL 기반으로 [타다 서비스](https://tadatada.com/) 개발
  - 배차 품질, 예상 운행요금, 위치 데이터 정합성 등 핵심 서비스 모니터링 및 개선
  - AI 에이전트를 활용한 코드 분석, 성능 개선 및 코드 리뷰 자동화
  - 메트릭과 로그를 활용한 서비스 및 AI 에이전트 관측 환경 구축
  - k8s, terraform 등 인프라 도구에 대해서 간단한 경험
- iOS 개발
  - [tuist](https://tuist.io/)를 활용한 프로젝트 설정 및 관리
  - RIBs, ReactorKit 등 다양한 아키텍처 경험
- 안드로이드 개발
  - 간단한 UI 개발 및 기능 구현
- Web 개발
  - React 기반 기능 개발 및 리팩토링
  - jotai, Redux 등 상태 관리 라이브러리 경험
  - 웹뷰 Bridge 개발 및 앱 환경 대응
